## Next Topic: Throughput Analysis of Switching Fabric with Input Queuing

This is the **last major topic in the Queuing Theory material you shared**, and it connects directly with your previous **Crossbar + Input Queuing + HOL Blocking** topic.

---

# 1. Why do we need throughput analysis?

Consider an **N × N switching fabric**.

* There are `N` input ports.
* There are `N` output ports.
* Packets arrive at input queues.
* In every time slot, the scheduler decides which packets can cross the fabric.
* An output can receive **at most one packet per slot**.

The question is:

> **What fraction of the maximum possible throughput can an input-queued switch achieve?**

Because of **HOL (Head-of-Line) blocking**, the answer is surprisingly less than 100%.

---

# 2. Assumptions

The analysis in your PPT assumes:

1. Fixed-length packets.
2. Slotted time.
3. There are `N` input ports and `N` output ports.
4. Every packet's destination is equally likely among the `N` output ports.
5. Each input has an input queue.
6. Only the **HOL packet** of each input queue is considered for scheduling.

Suppose:

```text
             Outputs
           O1 O2 O3 O4
            |  |  |  |
I1 ---------+--+--+--+
I2 ---------+--+--+--+
I3 ---------+--+--+--+
I4 ---------+--+--+--+
```

In each time slot, multiple packets can cross simultaneously **provided they don't request the same output**.

---

# 3. What happens in one time slot?

Suppose there are 4 inputs:

```text
Input 1 → Output 1
Input 2 → Output 1
Input 3 → Output 3
Input 4 → Output 4
```

We have:

```text
I1 → O1
I2 → O1
I3 → O3
I4 → O4
```

Both `I1` and `I2` want `O1`.

But an output can accept only **one packet** in a slot.

Therefore:

```text
O1 ← one packet
O3 ← one packet
O4 ← one packet
```

Maximum packets transmitted = **3**

Instead of 4.

The losing packet remains in the input queue.

---

# 4. Definition of ρ

Let

$$
\rho
$$

represent the **per-output-port throughput/utilization**.

If:

$$
\rho = 0.586
$$

then each output is successfully receiving packets at approximately:

$$
58.6\%
$$

of its maximum capacity.

For an `N × N` switch:

$$
E[F] = N\rho
$$

where:

* `F` = number of packets transferred in one slot
* `N` = number of outputs
* `ρ` = per-port throughput

Therefore:

$$
\boxed{\text{Switch Throughput}=N\rho}
$$

---

# 5. Introducing \(B_i\)

Your PPT defines:

> \(B_{i,m}\) = number of packets meant for output `i` but not transmitted in slot `m`.

For a particular output:

```text
Several HOL packets
       ↓
I1 → O1
I2 → O1
I3 → O1
I4 → O1
       ↓
Only ONE can be transmitted
```

The remaining packets are blocked.

So we analyze the number of packets waiting for each output.

The PPT obtains:

$$
E[B_i] = \frac{\rho^2}{2(1-\rho)}
$$

for the relevant queueing model.

---

# 6. Deriving switch throughput

We have:

$$
F_m=N-\sum_{i=1}^{N}B_{i,m}
$$

Taking expectation:

$$
E[F]
=
N-\sum_{i=1}^{N}E[B_i]
$$

Since all output ports are statistically identical:

$$
E[B_1]=E[B_2]=\cdots=E[B_N]
$$

Therefore:

$$
E[F]=N-NE[B_i]
$$

or

$$
\boxed{E[F]=N(1-E[B_i])}
$$

But we also know:

$$
E[F]=N\rho
$$

Therefore:

$$
N\rho=N(1-E[B_i])
$$

Cancel `N`:

$$
\rho=1-E[B_i]
$$

Using the queueing expression gives the equation whose solution is:

$$
\boxed{\rho\approx0.586}
$$

Thus:

$$
\boxed{\text{Maximum throughput}\approx58.6\%}
$$

under these assumptions.

---

# 7. Why is 58.6% important?

This is a **very important exam result**.

Even though the switch physically has enough capacity to potentially transfer:

$$
N
$$

packets per slot, input queuing with HOL blocking prevents full utilization.

Approximately:

$$
\boxed{58.6\%}
$$

of the ideal throughput is achieved under the classic random-destination HOL model.

This is one of the major reasons why **Virtual Output Queuing (VOQ)** is used.

---

# 8. Connection with HOL Blocking

Remember your previous topic:

### Input Queuing

Each input has one FIFO queue:

```text
Input 1:

[Packet → O1] [Packet → O3] [Packet → O2]
      ↑
     HOL
```

Suppose the first packet wants `O1`, but `O1` is busy.

Then:

```text
[Packet → O1] [Packet → O3] [Packet → O2]
      BLOCKED
                  ↓
             cannot move
```

Even though the second packet could potentially go to free `O3`, it cannot overtake the first packet.

That's **HOL blocking**.

---

# 9. Why VOQ solves this problem

Instead of one FIFO queue:

```text
Input 1
   |
   +---- Queue for O1
   |
   +---- Queue for O2
   |
   +---- Queue for O3
   |
   +---- Queue for O4
```

Now suppose:

```text
O1 ← busy
O3 ← free
```

The packet waiting for `O3` can still be transmitted.

Therefore, packets behind a blocked packet don't necessarily have to wait.

For an `N × N` switch:

$$
\boxed{N^2}
$$

VOQs are required.

---

# 10. Important comparison

| Architecture           | Main issue                |           Theoretical throughput |
| ---------------------- | ------------------------- | -------------------------------: |
| Input Queuing          | HOL blocking              | ~58.6% under classic assumptions |
| Output Queuing         | Requires very fast fabric |                             100% |
| Virtual Output Queuing | Complex scheduler         |                Can approach 100% |
| Crossbar + VOQ         | Scheduling complexity     |                        Very high |

# 12. Very important conceptual question

### Q: Why can't an input-queued crossbar achieve 100% throughput?

**Answer:**

Because of **Head-of-Line blocking**. A packet at the head of an input FIFO may be waiting for a busy output. Packets behind it may be destined for free outputs, but they cannot overtake the HOL packet. Consequently, some output transmission opportunities remain unused.

---

# 13. Scenario-based question

### Scenario

A router has a crossbar switching fabric with input FIFO queues. During a particular slot:

```text
I1 → O1
I2 → O1
I3 → O3
I4 → O4
```

Explain why all four packets cannot be transmitted simultaneously.

### Answer

`I1` and `I2` both request the same output `O1`. Since an output can accept only one packet during a time slot, the scheduler can select only one of these packets.

The other packet remains at the head of its input queue and may cause HOL blocking.

Therefore, only:

```text
I1 → O1
I3 → O3
I4 → O4
```

can be transmitted.

Total:

$$
\boxed{3\text{ packets}}
$$

---
